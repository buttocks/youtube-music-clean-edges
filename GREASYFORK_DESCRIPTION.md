# YouTube Music Clean Edges

A lightweight cleanup and quality-of-life userscript for the desktop YouTube Music website.

## Features

- Compact layout and slimmer scrollbars
- Audio Only toggle using YouTube Music's native Song / Video mode when available
- Automatically dismisses the "still listening / continue watching" prompt
- Persistent STOPS counter showing how many prompts were handled
- Optional promo-banner hiding
- Persistent settings through the userscript-manager menu
- Lightweight playback logic intended not to interfere with Shuffle or the queue

## Audio Only

Red `AUDIO` means off. Green `AUDIO ON` means enabled.

The script switches to YouTube Music's native Song mode when available rather than simply hiding the video image.

## STOPS

Counts automatically dismissed still-listening prompts. Click it to reset the count.

No ad blocker is included. Settings are stored locally and the script does not send data anywhere.
