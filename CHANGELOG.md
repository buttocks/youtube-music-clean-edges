# Changelog

## 3.5.0
- Public project name changed to **YouTube Music Toolkit** to better reflect the full feature set.
- Restored configurable toggles on top of the stable 3.4 playback logic.
- Added persistent toggles for compact layout, slim scrollbars, STOPS visibility, and promo hiding.
- Kept Audio Only and Shuffle behavior from the stable playback baseline.

## 3.4.0
- Fixed Audio Only repeatedly re-triggering Song mode.
- Added per-track handling to avoid interfering with Shuffle and queue state.
- Improved Audio Only response on track changes.
- Improved switching back to Video mode.

## 3.3.0
- Added native Video-mode restoration when Audio Only is turned off.

## 3.2.0
- Introduced a lower-overhead build for older PCs.
- Reduced broad DOM scanning and background work.

## 2.5.0
- Added persistent STOPS counter for automatic still-listening dismissals.

## 2.3.0
- Added persistent Audio Only toggle.
